# Corth

A small simple Forth-like interpreter
It's ment to be forth, but with a bit more modern and QoL fetures.

## Build

> This is made in mind for *nix systems!

to compile the project run

> [!NOTE]
> replace the CC var in the makefile if you do not use gcc

```
make
```
the executable files will be in bin.

```
./corth
```
## Examples

here is a list of simple examples to get started 

```corth
1 2 3 // this adds 1 2 3 to the stack
.s // this list's the stack
<3> 1 2 3
```
it works just like forth does.
